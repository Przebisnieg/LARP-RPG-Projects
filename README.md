# LARP & RPG Projects

A collection of interactive tools, maps, and web applications developed for Live Action Role-Playing (LARP) events and tabletop RPG campaigns.

This repository showcases personal programming projects created since **2025**, combining web development, interactive interfaces, and game-related tools.

Most applications were originally developed for Polish-speaking communities, so their interfaces and in-game content are primarily in Polish. Project documentation is provided in English.

## Projects

### 1. Galactic Map Editor (2025)

An interactive galaxy map developed for a science-fiction LARP campaign.

The project was designed to help participants explore a fictional universe, search for star systems, filter locations, and add visual annotations to the map.

**Key features:**
- Interactive SVG-based galaxy map
- Search and filtering of star systems
- Zooming and panning
- Drawing and editing tools
- Customizable colors and line widths
- Exporting annotated maps as images
- Controls adapted for different screen sizes

**Technologies:** HTML5, CSS3, JavaScript, SVG
