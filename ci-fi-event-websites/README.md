# Sci-Fi Event Websites

A collection of interactive event websites created for science-fiction LARP and RPG experiences.

These projects explore different approaches to frontend development, combining themed visual design, animations, interactive content, and event-related interfaces.

## Projects

### 1. Space Racing Competition — Challenge 17039

A fictional space racing competition website featuring participants, organizers, sponsors, competition stages, results, and animated visual effects.

**Key features:**
- Interactive competition results and rankings
- Tab-based navigation
- Password-triggered content reveals
- Participant and organizer galleries
- Animated backgrounds, scrolling news, and visual effects
- Responsive results tables

**Technologies:** HTML5, CSS3, JavaScript

[Source Code](space-racing-competition/) | [Live Demo](https://przebisnieg.github.io/LARP-RPG-Projects/ci-fi-event-websites/space-racing-competition/index.html)

### 2. Space Press Photo Invitation

An interactive nomination invitation for a fictional photography awards ceremony set in a science-fiction universe.

**Key features:**
- Themed invitation interface
- Animated backgrounds and glowing visual elements
- Interactive attendance confirmation
- Responsive layout

**Technologies:** HTML5, CSS3, JavaScript

[Source Code](space-press-photo-invitation/) | [Live Demo](https://przebisnieg.github.io/LARP-RPG-Projects/ci-fi-event-websites/space-press-photo-invitation/index.html)

## Language

Both applications were created for Polish-speaking LARP participants. Their interfaces and content are primarily in Polish.

## Notes

These are non-commercial frontend projects. Some images and animations are loaded from external sources.

The competition's password-based interactions are narrative features.

This project was created with AI tools.
