
# Space Racing Competition — Challenge 17039

An interactive competition website developed for a science-fiction LARP event.

[Source Code](space-racing-competition/) | [Live Demo](https://przebisnieg.github.io/LARP-RPG-Projects/ci-fi-event-websites/space-racing-competition/)


## Demo Passwords

Some sections of the website are unlocked by entering passwords. These passwords are part of the fictional competition experience and are provided below for demonstration purposes.

| Section | Password | Unlocks |
|---|---|---|
| Race Route | `SKOK` | Displays the race route map |
| Stage 2 Results | `SKOK` | Reveals the second-stage results |
| Stage 3 Results | `DELFT` | Displays the Delft winner |
| Stage 3 Results | `SREBRO` | Displays the Czyste Srebro winner |
| Stage 3 Results | `DREAM` | Displays the X-Dream winner |
| Stage 3 Results | `TRI` | Displays the Trinidad winner |

Passwords are case-insensitive.
