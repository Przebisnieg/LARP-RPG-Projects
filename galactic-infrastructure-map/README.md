# Galactic Infrastructure Map

| [Galactic Infrastructure Map](galactic-infrastructure-map/) | Interactive galaxy map featuring faction territories, star system information, and planetary infrastructure panels. | 2026 | [Live Demo](https://przebisnieg.github.io/LARP-RPG-Projects/galactic-infrastructure-map/) |

An interactive SVG-based galaxy map with planetary infrastructure panels, developed for a science-fiction Live Action Role-Playing (LARP) game.

The application allows players to explore a fictional galaxy, inspect star systems, identify faction territories, and view infrastructure information for selected planetary systems.

## Project Background

This project was created as a visual tool for a science-fiction LARP campaign featuring multiple factions, political territories, and planetary systems.

It was designed to provide a more accessible and immersive way to explore the fictional game world.

## Features

- **Interactive star map** — explore a large SVG-based galaxy.
- **Star system information** — display location names, faction affiliations, and descriptions.
- **Planetary infrastructure panels** — open dedicated views for selected star systems.
- **Infrastructure overview** — inspect available planetary and orbital infrastructure information.
- **Faction territories** — toggle the visibility of faction-controlled regions.
- **Sector grid** — show or hide the galactic coordinate grid.
- **Zooming and panning** — navigate the galaxy using mouse and touch controls.
- **Interactive tooltips** — display information near the selected star system.
- **Planetary illustrations** — view images associated with selected locations.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- SVG

## Language

The application interface and in-game content are primarily in **Polish**, as the project was created for a Polish-speaking LARP community.

The technical documentation is provided in English.

## Running the Project

1. Download or clone the repository.
2. Open `index.html` in a modern web browser.
3. Explore the galaxy and select star systems to view additional information.
4. Open the infrastructure panel for supported locations.

No backend or additional package installation is required.

## Current Limitations

- Some planetary infrastructure sections contain placeholder information.
- Illustrations are available for selected star systems only.
- Other supported locations may display placeholder images or information.
