# Galactic Map Editor

## Live Demo

[Open the Interactive Galactic Map](https://przebisnieg.github.io/LARP-RPG-Projects/galactic-map-editor/)

An interactive galaxy map and editing tool developed for a science-fiction Live Action Role-Playing (LARP) game.

The application was designed to help players explore a fictional galaxy, locate star systems, view information about different factions, and interact with the map during gameplay.

It also includes drawing and editing tools that allow users to mark locations, plan movements, and add visual annotations directly to the map.

## Project Background

This project was created to support a science-fiction LARP campaign featuring multiple factions, territories, and star systems.

The main goal was to provide an interactive alternative to a static map, making it easier to navigate the fictional universe and visualize in-game information.

## Features

- **Interactive galaxy map** — explore a large SVG-based star map.
- **Search** — locate individual star systems by name.
- **Filtering** — display systems based on factions, exploration status, and star types.
- **Drawing tools** — add shapes, lines, arrows, and other annotations.
- **Customizable annotations** — adjust drawing colors and line widths.
- **Map navigation** — zoom and pan across the galaxy.
- **Selection and editing** — interact with map elements and annotations.
- **Image export** — save the annotated map as a JPG image.
- **Responsive controls** — interface adjustments for smaller screens and touch devices.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- SVG
- html2canvas (image export)

## Language

The application interface and most of the in-game content are in **Polish**, as the project was developed for a Polish-speaking LARP community.

## Running the Project

1. Download or clone the repository.
2. Open `index.html` in a modern web browser.
3. Use the control panel to explore, filter, and annotate the galaxy map.

No backend or installation of additional packages is required for the basic application.

An internet connection may be required to load the external image-export library.
