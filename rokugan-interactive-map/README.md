# Interactive Rokugan Map

An interactive fantasy map developed as a digital reference tool for a Live Action Role-Playing (LARP) game set in the world of Rokugan.

**Created:**  2024/2025  
**Technologies:** HTML5, CSS3, JavaScript, SVG  
**Language:** Polish

## Project Background 

This project was developed to support a fantasy LARP campaign set in Rokugan, a fictional world inspired by Japanese culture and traditions.

The goal was to transform a traditional illustrated map into an interactive tool, allowing participants to explore territories and access additional information about the game world.

The application combines a detailed map with interactive SVG regions and a JavaScript-based collection of geographical and political information.

## Features

- **Interactive SVG map** — explore individual provinces and geographical regions.
- **Province information** — view information about locations, ruling clans, families, resources, and political status.
- **Clan territories** — identify areas controlled by different clans.
- **Interactive tooltips** — display additional information when interacting with map elements.
- **Visual highlighting** — highlight selected regions and territories using different colors.
- **Animated conflict regions** — visual effects indicate areas affected by warfare.
- **Geographical landmarks** — explore forests, rivers, lakes, castles, and other locations.
- **Responsive layout** — map dimensions adjust to different screen sizes.
- **Themed interface** — Japanese-inspired visual styling and animated background elements.

## Running the Project

1. Download or clone the repository.
2. Open `index.html` in a modern web browser.
3. Hover over map regions and locations to explore their information.

No backend or additional software installation is required.

An internet connection may be needed to load the external Google Font.
